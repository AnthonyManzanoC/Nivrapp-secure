# Nivra 10.2.1

Esta versión corrige la comprobación y la descarga de actualizaciones en el cliente de Windows. El actualizador acepta los enlaces válidos del CDN de GitHub Releases y conserva la verificación del tamaño y del SHA-256 del instalador.

Android se publica como build 65 con el certificado existente. La API conserva la compatibilidad con 10.2.0 y queda disponible para despliegue manual. La web permanece en pausa.
