Antes del primer hola.

¿Necesito un número de teléfono?+

No. Puedes crear una cuenta privada y usar tu ID Nivra o alias junto con tu contraseña.

¿Puedo usar Nivra sin instalar la app?+

Sí. Selecciona «Abrir Nivra Web» para entrar desde tu navegador. También puedes descargar las versiones para Android y Windows.

¿Cómo entro si ya tengo una cuenta?+

Selecciona «Entrar» e inicia sesión con tu ID Nivra o alias. En la pantalla de acceso también encontrarás la opción de vinculación por QR.
